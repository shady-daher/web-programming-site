Internet and Web: What Is the Difference?

The Internet and the Web are not the same thing. The Internet is the worldwide network infrastructure that connects computers and networks. The Web is a service that runs on the Internet and uses technologies such as HTML, HTTP, and URIs/URLs.

Web Timeline

Major events in the development of the World Wide Web.

  1. 1989 - The Web Is Proposed

    In 1989, Tim Berners-Lee, while working at CERN, proposed a system based on hypertext that would allow information to be connected and accessed through a network.

    Why it mattered: The proposal provided the basic idea that developed into the World Wide Web.

    Source: CERN - The Birth of the Web

  2. 1990 - First Web Server and Browser

    In 1990, Tim Berners-Lee created the first Web server and Web browser at CERN using a NeXT computer.

    Why it mattered: The first working server and browser turned the idea of the Web into a usable system.

    Source: CERN - A Short History of the Web

  3. 1991 - Web Software Released

    In 1991, the Web software, including the browser and server, was made available and announced on Internet newsgroups in August.

    Why it mattered: Making the software available allowed people outside CERN to learn about and use the Web.

    Source: CERN - A Short History of the Web

  4. 1993 - CERN Makes Web Software Freely Available

    On April 30, 1993, CERN made the Web software freely available to the public. It was placed in the public domain and later released under an open licence.

    Why it mattered: Free availability helped the Web spread and encouraged wider development and use.

    Source: CERN - The Birth of the Web

  5. 1993 - Mosaic Browser

    In 1993, the NCSA released the Mosaic Web browser for Macintosh and Windows computers.

    Why it mattered: Mosaic helped make the Web more accessible to a wider audience.

    Source: W3C - History

  6. 1994 - W3C Founded

    In October 1994, Tim Berners-Lee founded the World Wide Web Consortium (W3C) at MIT, in collaboration with CERN and with support from DARPA and the European Commission.

    Why it mattered: The W3C helped coordinate the development of common Web standards.

    Source: W3C - History

Three Key Web Technologies

1. HTML
HyperText Markup Language is used to structure information and documents on the Web.
2. HTTP
HyperText Transfer Protocol is used for communication between Web clients and servers.
3. URI/URL
Uniform Resource Identifiers identify resources, while URLs provide addresses that can be used to locate resources on the Web.
