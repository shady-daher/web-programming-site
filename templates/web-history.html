History of the Internet

Introduction

The World Wide Web is different from the Internet. The Internet is the underlying network infrastructure, while the Web is a system for accessing and linking information through that network. Tim Berners-Lee invented the Web at CERN in 1989 to improve information sharing among researchers. Its early development was based on technologies such as HTML, HTTP, and Web addressing through URIs and URLs.

Web Timeline

1989 : World Wide Web proposed

In March 1989, Tim Berners-Lee wrote his first proposal for the World Wide Web while working at CERN. The idea was to connect information using hypertext so researchers could share information more easily.

Why it mattered: The proposal established the basic concept that later became the World Wide Web.

Source: https://home.cern/science/computing/the-birth-of-the-web/short-history-web/

1990 : First Web server and browser

By the end of 1990, Berners-Lee had the first Web server and browser running at CERN on a NeXT computer.

Why it mattered: This turned the Web from a proposal into a working system for creating and accessing Web documents.

Source: https://home.cern/science/computing/the-birth-of-the-web/short-history-web/

1991 : Web software released

In 1991, Berners-Lee released the World Wide Web software, including the browser and server software. The project was announced on Internet newsgroups in August.

Why it mattered: This allowed other researchers to access the software and begin using and developing the Web.

Source: https://home.cern/science/computing/the-birth-of-the-web/short-history-web/

1993 : CERN makes Web software freely available

On April 30, 1993, CERN put the World Wide Web software in the public domain and later made a release available under an open licence.

Why it mattered: Removing licensing barriers helped the Web spread and encouraged wider development and use.

Source: https://home.cern/science/computing/the-birth-of-the-web/

1993 : Mosaic helps popularize the Web

NCSA released Mosaic in 1993, and versions became available for popular computer platforms including Macintosh and Windows.

Why it mattered: Mosaic provided a more accessible browsing experience and contributed to the rapid growth of the Web.

Source: https://www.w3.org/wiki/The_history_of_the_Web

1994 : W3C is founded

In October 1994, Tim Berners-Lee founded the World Wide Web Consortium (W3C) at MIT in collaboration with CERN, with support from DARPA and the European Commission.

Why it mattered: W3C helped coordinate Web standards and promote a consistent architecture as the Web expanded.

Source: https://www.w3.org/about/history/

Three Key Web Technologies

1. HTML : HyperText Markup Language

HTML is the markup language used to structure Web documents. It provides elements such as headings, paragraphs, links, and images.

2. HTTP : HyperText Transfer Protocol

HTTP is a communication protocol used by Web clients and servers to exchange Web resources. It provides the basic communication mechanism between a browser and a Web server.

3. URI/URL : Web Addressing

URIs identify resources on the Web, while URLs are commonly used to specify where resources can be accessed. They allow Web resources to be referenced and linked.
