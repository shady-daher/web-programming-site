Introduction

The World Wide Web is not the same thing as the Internet. The Internet is the network that connects computers around the world, while the Web is a system used to access and connect information through that network. The Web was invented by Tim Berners-Lee at CERN in 1989 to make information sharing between researchers easier.

Web Timeline

1989: World Wide Web proposed

In 1989, Tim Berners-Lee wrote his first proposal for the World Wide Web while working at CERN. His idea was based on connecting information using hypertext.

Why it mattered: The proposal introduced the basic idea of the Web and how information could be connected between different computers.

Source: CERN

1990: First Web server and browser

By the end of 1990, Tim Berners-Lee had created the first Web server and Web browser at CERN. The first server ran on a NeXT computer.

Why it mattered: The Web became a working system that could be used to create and access Web documents.

Source: CERN

1991: Web software released

In 1991, Tim Berners-Lee released the World Wide Web software, including the browser and Web server. The project was announced on Internet newsgroups in August.

Why it mattered: Other researchers could begin using the software and developing their own Web content.

Source: CERN

1993: CERN makes Web software freely available

On April 30, 1993, CERN placed the World Wide Web software in the public domain.

Why it mattered: Making the software freely available helped the Web spread and encouraged people and organizations to develop it.

Source: CERN

1993: Mosaic helps popularize the Web

NCSA Mosaic became an important early Web browser in 1993 and was made available for platforms such as Macintosh and Windows.

Why it mattered: Mosaic made browsing the Web easier for more users and helped contribute to the rapid growth of the Web.

Source: W3C

1994: W3C is founded

Tim Berners-Lee founded the World Wide Web Consortium (W3C) in 1994 at MIT, with support from CERN, DARPA, and the European Commission.

Why it mattered: W3C helped coordinate Web standards and encouraged a more consistent Web as it continued to grow.

Source: W3C

Three Key Web Technologies

HTML: HyperText Markup Language

HTML is the markup language used to structure Web documents. It provides elements such as headings, paragraphs, links, and images.

HTTP: HyperText Transfer Protocol

HTTP is a communication protocol used by Web browsers and servers to exchange Web resources.

URI/URL: Web Addressing

URIs identify resources on the Web, while URLs are commonly used to specify where resources can be accessed. They allow Web resources to be referenced and linked.
