Introduction

The World Wide Web was created to make it easier for people to access and share information over the Internet. Tim Berners-Lee proposed the Web in 1989 while working at CERN. The first Web server and browser were created soon after.

Web Timeline

1989: The World Wide Web is proposed

In 1989, Tim Berners-Lee proposed a system that would allow information to be shared between computers using the Internet.

Why it mattered: This proposal became the starting point for the World Wide Web.

Source: CERN

1990: First Web server and browser

By the end of 1990, the first Web server and Web browser had been created at CERN.

Why it mattered: It showed that the proposed Web could actually be used to access and share information.

Source: W3C

1991: Web software is released

In 1991, the Web software was made available outside CERN. This allowed other people to start using and developing the Web.

Why it mattered: The Web began spreading beyond its original environment at CERN.

Source: CERN

1993: CERN makes the Web freely available

In 1993, CERN made the Web software available freely. This helped people and organizations use and develop the Web.

Why it mattered: Making the technology freely available helped the Web grow quickly.

Source: CERN

1993: Mosaic helps popularize the Web

The Mosaic browser became an important part of the early growth of the Web because it made browsing easier for many users.

Why it mattered: Mosaic helped bring the Web to a much wider audience.

Source: W3C

1994: W3C is founded

In 1994, the World Wide Web Consortium, known as W3C, was founded by Tim Berners-Lee.

Why it mattered: W3C helped develop and maintain standards for the Web.

Source: W3C

Three Key Web Technologies

HTML

HTML is used to structure the content of Web pages. It defines elements such as headings, paragraphs, links, and other page content.

HTTP

HTTP is a protocol used for communication between Web browsers and Web servers.

URI and URL

URIs identify resources on the Web, while URLs provide addresses that can be used to locate those resources.
